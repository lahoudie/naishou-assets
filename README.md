# Images de Naishou

Ressources graphiques publiées pour le jeu. Les fichiers objects/ sont nommés par SHA-256 et ne doivent jamais être modifiés ni supprimés. Les anciennes versions restent accessibles.

Le dépôt du jeu conserve les originaux et génère manifest.json avec scripts/prepare-image-hosting.mjs. Publier les images et vérifier leurs empreintes avant la publication du jeu. GitHub Pages sert la branche main, dossier /.

Aucune licence de réutilisation des illustrations n’est accordée par ce dépôt.

## Musiques

Les copies complètes de The Crow Clan et The Fallen sont dans audio/, sous des noms SHA-256 immuables. music-manifest.json décrit leurs albums, numéros, durées et empreintes. Les originaux restent dans les dossiers sources de l’auteur ; scripts/prepare-music.mjs du jeu prépare les copies de diffusion. Ne jamais modifier ni supprimer les anciens objets audio. Aucune licence de réutilisation des musiques n’est accordée par ce dépôt.
